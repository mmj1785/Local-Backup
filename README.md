# Backup Tool (أداة النسخ الاحتياطي التراكمي الذكي) 🛡️

أداة نسخ احتياطي احترافية لنظام Windows مبنية باستخدام **Python** و **PyQt6**، تعتمد على محرك **Robocopy** فائق السرعة لنقل الملفات محلياً أو عبر خوادم الشبكة (SMB/Shared Folders).

---

## ✨ المميزات الرئيسية

1. **النسخ التزايدي الذكي (Incremental Backup):**
   * نسخ الملفات الجديدة والمعدلة فقط، مع تجاوز الملفات المتطابقة مسبقاً لتوفير الوقت واستهلاك الشبكة.
   * إمكانية العمل بنظام التراكم اليومي طوال الشهر؛ حيث تُضاف الملفات الجديدة في كل تشغيل دون حذف أي ملفات سابقة في مجلد الوجهة.

2. **وضع آمن افتراضي (لا حذف ولا استبدال):**
   * المصدر للقراءة فقط: لا `/MOVE` ولا `/PURGE`، وأعلام الحذف/النقل ممنوعة برمجيًا (`/MOV /MOVE /PURGE /MIR`) ويرفضها البرنامج قبل التنفيذ.
   * الوجهة لا يُحذف منها شيء: خيار `mirror` ممنوع، والحذف التلقائي للنسخ القديمة (`retention`) معطّل إلا بـ `retention_enabled: true` صراحةً.
   * لا يُستبدل أي ملف موجود في الوجهة (`/XC /XN /XO`): يُنسخ الجديد فقط، وأي ملف موجود بنسخة مختلفة يُسجَّل تحذيرًا ويبقى كما هو. للسماح بالاستبدال: `overwrite_existing: true`.

   (سابقًا:) **أمان وحماية تامة لملفات المصدر:**
   * عملية القراءة من المصدر آمنة 100% (`Read-Only`) دون أي مساس أو تعديل أو نقل أو حذف لبيانات المصدر الحساسة.

3. **تخصيص مجلد وجهة مستقل لكل مصدر:**
   * يمكنك إضافة مصادر متعددة، وتحديد مجلد وجهة مخصص ومستقل لكل مسار، مما يمنع تداخل الملفات.

4. **واجهة رسومية عصرية (Modern Dark UI):**
   * مبنية بأحدث معايير **PyQt6** مع شريط جانبي للتنقل السلس.
   * خالية تماماً من الشاشات السوداء المزعجة لسطر الأوامر (`robocopy.exe`).
   * شريط تقدم يوضح اسم الملف الجاري نسخه في الوقت الفعلي مع بطاقة نتيجة خضراء/حمراء واضحة.
   * تصميم متجاوب يدعم تصغير وتكبير النافذة وملء الشاشة بحرية دون تشوه المحتويات.

5. **منع تداخل المصادر والوجهات:**
   * قبل أي نسخ يفحص البرنامج: وجهتان متطابقتان أو إحداهما داخل الأخرى، وجهة داخل مصدرها أو داخل مصدر آخر، أسماء مكررة. عند أي تداخل لا يكتب شيئًا ويعرض السبب.
   * الفحص يتم أيضًا لحظة إضافة الصف في الجدول. (لا يكتشف أن `E:` مربوط بنفس مشاركة الشبكة `\\srv\share` — استخدم مسارات متسقة.)

6. **تقدم حقيقي وإيقاف آمن:**
   * النسبة محسوبة بالبايت المنسوخ فعليًا من حجم المصدر، وشريط واحد يمثل التقدم الكلي لكل المصادر.
   * زر **إيقاف** يوقف robocopy فورًا ولا يبدأ المصادر التالية؛ الملفات المنسوخة تبقى ويمكن إكمال الباقي لاحقًا.

7. **فحص ومطابقة سلامة البيانات (Verification):**
   * فحص ذكي يتأكد من وصول كافة ملفات المصدر إلى الوجهة وتطابق أحجامها بالكامل، دون اعتبار وجود ملفات إضافية بالهدف كخطأ.

8. **دعم السيرفرات ومشاركات الشبكة:**
   * مصادقة واتصال مباشر بالسيرفر عبر بروتوكول SMB/IPC$ مع إمكانية استعراض المشاركات العادية والإدارية المخفية (`C$`, `D$`).

## 🚀 طريقة الاستخدام من الواجهة

1. **الاتصال بالسيرفر (اختياري):**
   * إذا كانت المجلدات موجودة على سيرفر في الشبكة، انتقل إلى تبويب **الاتصال** وأدخل عنوان IP واسم المستخدم وكلمة المرور، ثم اضغط **اتصال**. (في حال كانت الملفات محلية على جهازك، لا حاجة للاتصال).
2. **إدارة المسارات:**
   * انتقل إلى تبويب **المسارات**.
   * أدخل اسماً للمجلد (مثلاً: `المالية`).
   * حدد **مجلد المصدر** عبر زر "محلي" أو "سيرفر".
   * حدد **مجلد الوجهة** المخصص له عبر زر "محلي" أو "سيرفر".
   * اضغط **إضافة** ➕ (يمكنك إضافة عدة مسارات مختلفة).
   * يمكنك حفظ المسارات والإعدادات عبر زر **حفظ الإعدادات** لاسترجاعها لاحقاً بضغطة زر.
3. **التشغيل والمتابعة:**
   * انتقل إلى تبويب **التشغيل** واضغط **بدء النسخ الاحتياطي الآن**.
   * سيتم النسخ بهدوء وسرعة، وستظهر لك رسالة نجاح خضراء عند اكتمال التحقق من سلامة كافة الملفات.

## 🛠️ البناء وإنشاء ملف التثبيت

### 1. تشغيل التطبيق من السورس كود:
```bash
pip install -r requirements.txt
python gui_backup_tool.py
```

### 2. بناء الملف التنفيذي `BackupTool.exe`:
قم بتشغيل الملف:
```cmd
build.bat
```
سيتم إنشاء الملف في المجلد:
`dist\BackupTool\BackupTool.exe` (مجلد كامل، لأن البناء `--onedir`)

### 3. إنشاء ملف التثبيت (Setup Wizard):
افتح الملف [`BackupTool.iss`](BackupTool.iss) باستخدام برنامج **Inno Setup Compiler** واضغط على **Compile**.
سَيُنتج لك ملف تثبيت احترافي في مجلد:
`Output\BackupToolSetup-v2.0.exe`

## ⚙️ ملاحظات للمطور
* `.gitignore` يستثني `build/` و`dist/` و`__pycache__/`. لو كانت متتبَّعة سابقًا: `git rm -r -q --cached build dist __pycache__`.
* كلمة مرور SMTP (للـ CLI): يمكن تمريرها بمتغير البيئة `BACKUP_SMTP_PASSWORD` بدل كتابتها في `config.yaml`.
* ملفات الإعدادات: لكل مصدر `destination` صريحة؛ أو `target_root` (قديم/CLI) فيُنشأ مجلد باسم المصدر داخله.
